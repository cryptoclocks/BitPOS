# เทียบฟีเจอร์ domepos กับ BitPOS (2026-11-02)

แหล่ง: README / CLAUDE.md / HANDOFF.md และป้ายข้อความใน UI ของ `jaturapornchai/domepos` (อ่านเพื่อดูรายการฟีเจอร์เท่านั้น **repo ไม่มี license จึงไม่คัดลอกโค้ด/ภาพ/ข้อความ** ทุกอย่างเขียนใหม่เอง) ถ้าต้องการนำโค้ดมาใช้จริง ต้องให้เจ้าของ repo ใส่ license ก่อน

| ฟีเจอร์ใน domepos | สถานะใน BitPOS | การตัดสินใจ |
|---|---|---|
| ใบเสร็จย่อ 80 มม. | ไม่มี → **ทำแล้ว** (`print-slip.ts`, `PrintActions.tsx`) | ยังไม่ทดสอบกับเครื่องพิมพ์จริง |
| สติกเกอร์แปะแก้ว | ไม่มี → **ทำแล้ว** | เหมือนด้านบน |
| Z-Report พิมพ์ได้ | มีปิดรอบอยู่แล้ว (`ShiftClose`) ไม่มีพิมพ์ → **เพิ่มปุ่มพิมพ์แล้ว** | |
| เรียกคิวด้วยเสียงไทย | ไม่มี → **ทำแล้ว** (`voice-call.ts`) | ต้องมีเสียงไทยในเครื่อง |
| เสียงเอฟเฟกต์ (เพิ่ม/ลบแก้ว, ออเดอร์ใหม่) | ไม่มี → **ทำแล้ว** (`sfx.ts`, `SoundToggle.tsx`, ปุ่มปิดเสียง จำค่าในเบราว์เซอร์) | ไม่มีไฟล์เสียง สังเคราะห์ในเครื่อง |
| ค้นหาเมนู / กรองหมวด | **มีอยู่แล้ว** (`Pos.tsx`, `TableMenu.tsx`) | ไม่ต้องทำ |
| ผังโต๊ะ / พักบิลต่อโต๊ะ | **มีอยู่แล้ว** (สั่งที่โต๊ะ + table session) | ไม่ต้องทำ |
| จอคิวครัว (KDS) สถานะ รับ→ทำ→พร้อม→รับแล้ว | **มีอยู่แล้ว** (`IncomingOrders` fulfillment) + คิวครัว Grab | ไม่ต้องทำ |
| จัดการเมนู/ราคา/รูป/หมวด | **มีอยู่แล้ว** (`CatalogEditor`, upload รูป) | ไม่ต้องทำ |
| ตัวเลือกความหวาน/ท็อปปิ้ง | **มีอยู่แล้ว** (`OnlineOptionsSettings`) | ไม่ต้องทำ |
| ปิดกะ / รายงานยอด | **มีอยู่แล้ว** (`ShiftClose`, `PosReports`) | |
| ยกเลิกบิล | **มีอยู่แล้ว** (`canCancel`, ทบทวนยกเลิก) | |
| สะสมแต้ม (100 ฿ = 1 แต้ม) | **มีอยู่แล้วในแบบของ BitPOS** (reward/loyalty + NFT badge) | ไม่ลอกกติกา |
| บาร์โค้ด / สแกนเพิ่มสินค้า | ไม่มี → **ทำแล้ว** (migration 183 ตาราง `product_barcodes` แยก ไม่แตะสัญญา product/มือถือ; สแกนตรงเป๊ะเท่านั้น) | ดู `CASH_REGISTER_DESIGN_TH.md` |
| ขายด่วนเงินสดพอดี / รับเงินสด-ทอน | ไม่มี → **ทำแล้ว** เป็นโมดูลแยก (`cash_sales`) ไม่ปน `orders` ที่ต้องผ่านการตรวจบนเชน; ราคาเงินสด THB แยกชุด ไม่แปลงอัตราแลกเปลี่ยน | ดูเอกสารออกแบบ |
| PromptPay / โอน / บัตร | ไม่มี | **ไม่ทำ** ต้องมีตัวตรวจจากผู้ให้บริการจริง (ลายเซ็น/callback ไม่ใช่หลักฐาน) |
| ส่วนลดท้ายบิล | ไม่มี → **ทำแล้วในขายเงินสด** (% หรือจำนวนเงิน, ปัดลง, ต้องน้อยกว่ายอดรวม, พนักงานลดได้ไม่เกินเพดานที่เจ้าของตั้ง) | ไม่แตะราคา crypto |
| ใบกำกับภาษีอย่างย่อ / VAT 7% | ไม่มี → **ทำแล้ว** (VAT รวมในราคา, เลขที่เรียงต่อเนื่อง, snapshot ผู้ขาย) | **ยังไม่ผ่านการตรวจโดยนักบัญชี/สรรพากร** UI มีคำเตือน ห้ามอ้างว่าถูกกฎหมายครบ |
| บันทึกบัญชี GL คู่ (Debit=Credit) | ไม่มี | ไม่ทำ ขนาดใหญ่ ต้องเป็นโครงการแยก |
| Cloudflare D1/R2 sync, SSE | ไม่ใช้ (BitPOS ใช้ Supabase บน OCI) | ไม่ทำ ขัดสถาปัตยกรรม |
| ไม่มีหน้า login (solo owner) | ตรงข้ามกับกฎของ BitPOS (role ฝั่งเซิร์ฟเวอร์) | **ไม่ทำโดยเจตนา** |
| UAT runner / วิดีโอ / MCP | เครื่องมือของ repo นั้น | ไม่เกี่ยว |

## อัปเดต 2026-11-02 (รอบปิดช่องว่าง)

| ฟีเจอร์ | สถานะ |
|---|---|
| ความหวาน / ท็อปปิ้งรายแก้วในเครื่องคิดเงินสด | **ทำแล้ว** — เจ้าของเปิดเลือกความหวานต่อเมนู และตั้งท็อปปิ้ง (ราคาบวกเพิ่ม) ต่อเมนู; ราคาคิดที่เซิร์ฟเวอร์; ใบเสร็จเก็บสำเนา (migration 184) |
| เปิดกะ + เงินทอนตั้งต้นในลิ้นชัก | **ทำแล้ว** — บันทึกครั้งเดียวต่อรอบ แก้ไม่ได้; "ควรมีในลิ้นชัก" = เงินตั้งต้น + ขายเงินสด; ปิดรอบเก็บตัวเลขนี้และแสดงส่วนต่างกับยอดที่นับได้ |
| ขายด่วนเงินสดพอดี 1 คลิก | **ทำแล้ว** |
| หน่วยนับสินค้า | **ทำแล้ว** (ต่อราคาเงินสด แสดงในการ์ด/บิล/ใบเสร็จ) |
| พักบิลเข้าโต๊ะ/บาร์ แล้วเรียกกลับ | **ทำแล้ว** — ไม่จองสต็อก ราคาและสต็อกตรวจใหม่ตอนขาย; เรียกกลับได้ครั้งเดียว; จำกัด 50 บิล |
| CSV ส่งออกยอดขายเงินสด | **ทำแล้ว** (`kind=cash`) |
| เพิ่ม/ลบสินค้าในหน้าจัดการเมนู | มีอยู่แล้ว (`createProduct`/`archiveProduct`, ลบ = เก็บถาวร) |
