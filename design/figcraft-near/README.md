# BitPOS × NEAR · ไฟล์ออกแบบ FigCraft (Living Bill)

เปิด **[BitPOS-NEAR-UI.figcraft](BitPOS-NEAR-UI.figcraft)** ใน FigCraft แล้วเริ่มที่หน้า `00 · Flow` เฟรม `N00-flow-map` ทุกกล่องและทุกปุ่มกดไปหน้าถัดไปได้ (Prototype)

ไฟล์นี้สร้างใหม่จากศูนย์ ไม่ได้ต่อจากไฟล์ master ของ BitPOS และไม่ฝังรูปภาพใด ๆ จึงไม่มีโลโก้หรือภาพหน้าจอของบุคคลที่สาม สีและตัวอักษรเป็นของ BitPOS เอง ไม่ใช่แบรนด์ของ NEAR

| หน้า (Page) | เฟรม | ขนาด |
|---|---|---|
| `00 · Flow` | `N00-flow-map` แผนที่ทุกหน้าจอ | 1600×1000 |
| `10 · Merchant` | `NM-01` … `NM-11` แท็บ NEAR ของร้าน | 1440×1000 |
| `20 · Customer` | `NC-01` … `NC-08` + ภาษาไทย `NC-02-th`, `NC-05-th`, `NC-06-th`, `NC-07-th` | 390×844 |
| `30 · Staff` | `NS-01`, `NS-02` | 390×844 |
| `40 · BitPOS Mini` | `ND-01` … `ND-07` + ภาษาไทย `ND-02-th`, `ND-04-th` | 480×320 |

รวม 35 เฟรม ตรงกับตารางหน้าจอใน [near-hackathon/PLAN_TH.md](../../near-hackathon/PLAN_TH.md) หัวข้อ 8 (29 หน้า + 6 หน้าภาษาไทย)

## สร้างใหม่

```bash
python3 -I design/figcraft-near/source/build_near_ui.py
```

สคริปต์วาดทุกหน้าเป็น SVG (`source/screens/`), นำเข้า FigCraft ผ่าน `~/.local/bin/figcraft-cli` แบบไม่เปิดแอป, ต่อ hotspot เป็นลิงก์, ตรวจเส้นทาง แล้วจึงเขียนไฟล์ ถ้าการตรวจข้อใดไม่ผ่าน สคริปต์จะหยุดและไม่เขียนทับไฟล์เดิม ผลลัพธ์เหมือนเดิมทุกครั้ง (sha256 เท่ากัน)

ตรวจเส้นทางอย่างเดียว:

```bash
python3 -I design/figcraft-near/source/check_routes.py
```

## สิ่งที่ตรวจ (`reports/build-report.json`)

- ทุกเฟรมในแผนมีครบ อยู่ถูกหน้า ขนาดถูก
- ทุกลิงก์และ flow ชี้ไปเฟรมที่มีจริง · ไม่มี hotspot ค้างที่ยังไม่ต่อ
- ทุกเฟรมไปถึงได้จาก `N00-flow-map` ด้วยการกดลิงก์ · ไม่มีหน้าทางตัน
- ทุกคู่ "เข้าจาก → ไป" ในตารางเส้นทางของแผนมีลิงก์จริง (`source/routes.py`)
- ไม่มีจุดกดซ้อนกันที่ไปคนละหน้า · จุดกดอยู่ในเฟรม
- ข้อความไม่ล้นเฟรม (วัดด้วยเครื่องยนต์ตัวอักษรของ FigCraft เอง) · ทุกชั้นอยู่ในเฟรมและในกลุ่มของตัวเอง
- ทุกเฟรมมีป้าย `NEAR testnet` · `NC-04` มีป้าย `concept` · หน้าข้ามเชนมีป้าย `Mainnet preview · not executed`
- หน้าอังกฤษไม่มีข้อความไทย (ยกเว้นปุ่มสลับภาษา) · หน้า `-th` เป็นภาษาไทย
- ไม่มีรูปภาพฝังในไฟล์

## ไฟล์

- `source/` สคริปต์และ SVG ต้นทาง · `source/routes.py` คือตารางเส้นทาง
- `previews/` PNG ของทุกเฟรม (ส่งออกจากไฟล์ `.figcraft` จริง) · `reports/contact-*.png` ภาพรวมรายหน้า
- `handoff/screen-map.json` (รหัส, หน้า, ขนาด, ทางเข้า, ปลายทาง, เส้นทาง runtime ที่วางแผนไว้), `handoff/interaction-map.json`, `handoff/tokens.json`

ข้อมูลทั้งหมดเป็นข้อมูลสมมติ (Orbit Café, บิล 5.00 tUSD = 3.55 + 0.50 + 0.35 + 0.60) QR ในภาพสแกนไม่ได้ `NC-04` เป็นภาพแนวคิดของหน้าต่างกระเป๋า ไม่ใช่หน้าจอของกระเป๋าจริง หน้าจ่ายข้ามเชนและส่งเงินกลับบ้านเป็นตัวอย่าง quote เท่านั้น ไม่มีการส่งธุรกรรม
