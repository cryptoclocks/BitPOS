# 2026-10-28 — /meta moved to the existing OCI stack

The owner approved this move in chat: back up the database, apply migrations 300–304, start a separate `/meta` container, and route only `/meta/*` through the existing tunnel. The running `bitpos-runtime` api, worker, web, proxy and tunnel containers and their files were not touched.

## 1. Backup
- Tool: `tools/runtime/backup-bitpos-db.py` from the main checkout, which runs `pg_dump --schema=bitpos --format=custom` and verifies the archive with `pg_restore --list`.
- Archive `bitpos-20261028T052035Z.dump`: 75,284,842 bytes, sha256 `a5cd3cbb…36672d7`, mode 600, kept in the main checkout's git-ignored `local/private/db-backups/`. No restore was run.

## 2. Migrations 300–304
- Migration 300 was added to the approved set "301–304" because migration 303 references its `meta_ai_invocations` table. All five migrations create only new `meta_*` tables and functions, plus grants and RLS for `bitpos_app`. No existing table is altered.
- I ran all five in a single transaction that ended in ROLLBACK first: 16 tables were created, then rolled back.
- I then applied them in one transaction, with each migration recorded in `public.bitpos_migrations` and `lock_timeout` set to 5 s.

## 3. Separate container
- Compose project `bitpos-meta` (`infra/meta/compose.yaml`):
  - Image: the existing `bitpos-runtime:current`, with no new build (the disk is 95% full).
  - The hackathon source subset (no tests, no secrets) is mounted read-only at `/app/meta-src`.
  - Runs as uid 1001 on host networking, bound to 127.0.0.1:3102, with a 256 MB memory limit.
- Private env file `~/bitpos-private/meta/meta.env` (mode 600):
  - Database: the runtime's `bitpos_app` URL, so queries go through RLS.
  - Tap master key: newly generated on the server; it is not the local key.
  - Messenger, Stripe test and Meta API keys were copied server to server and were never printed.
- Catalog compatibility: the hackathon `effectiveCatalog` read BitPOS Purple Cafe from the migration-161 schema without errors (12 products, all priced in USD, all available).
  - It found no approved offers, so no offer is shown until the owner approves a promotion.
  - The check ran in a throwaway container. A first attempt inside the service container ran out of memory; the service restarted by itself and is healthy.
