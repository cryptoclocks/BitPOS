19 กระเป๋าสำหรับสองร้าน ลูกค้า ทีมปฏิบัติการ และกรณีทดสอบผิดเงื่อนไข หน้านี้แสดงเฉพาะ public address กับ snapshot ยอดบน Solana Devnet คีย์อยู่ในโฟลเดอร์ส่วนตัวบน Mac

เริ่มด้วย 1 SOL แล้วแจกให้ทุก role ที่ใช้ค่าธรรมเนียม

ชุดเริ่มต้นมีเป้าหมายรวม 0.78 SOL สำหรับทดสอบจ่าย USDG, คืนเงิน และ fee sponsor ต้องมีอย่างน้อย 0.79 SOL ใน reserve ก่อนแจก เป้าหมายสำรองเต็ม 16 SOL ใช้เติมภายหลัง; เงินชุดเริ่มต้นของ deployer ยังไม่ใช่งบ deploy โปรแกรมเต็มรูปแบบ

เปิด Solana Foundation faucetPine Stake faucet

ลองขอ 1 SOL เข้าที่อยู่สำรองผ่านหน้า faucet ด้วยตนเอง โควตาพื้นฐานของ Foundation แยกจากขั้นตอน GitHub เพื่อเพิ่มวงเงิน; ผู้ให้บริการอาจปฏิเสธคำขอหรือจำกัดโควตา Devnet SOL และ USDG ทดสอบไม่มีมูลค่าเงินจริง

DevnetFaucet.org · ช่องทาง 20 SOL ตรวจ repository ใน Solana ecosystem ด้วย บัญชีนี้ได้รับข้อความ “No eligible repository found” ต้องผ่าน Request Access / vouch ก่อนตามขั้นตอนหน้าเว็บ การเลือก anonymous ไม่ข้ามเกณฑ์สิทธิ์

เมื่อเงินเข้า ใช้ node tools/devnet/fund.cjs distribute-starter จากโฟลเดอร์ BitPOS เพื่อแจกชุดเริ่มต้น คง customer-no-sol ที่ 0 SOL สำหรับทดสอบ sponsorship
